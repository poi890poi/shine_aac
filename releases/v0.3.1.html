SHINE AAC v0.3.1

Android version code: 50

Optional block scanning

  • Added an optional Blocks, then rows and columns mode alongside row/column scanning.
  • Both modes reuse the same communication board, suggestions, and independently optimized language layouts.
  • The built-in boards use four balanced row groups, with a visible block outline during row scanning.
  • Single-row blocks and single-item rows advance or activate automatically.
  • Auto Demo supports both scanning modes.

Consistent English input

  • English remains a four-column board; the six-column Traditional Chinese layout does not affect it.
  • The fixed I remains in the frequency-ordered spelling area: E T A O, then I N S R.
  • That key enters the pronoun I at a word boundary and lowercase i inside a word.
  • One-character predictions are excluded, avoiding duplication with the fixed alphabet.

Interface and compatibility

  • Pause and stopped-state labels are shorter to avoid clipping on phones.
  • Default configurations migrate to the corrected English layout and scan-mode setting; custom boards and dictionaries remain unchanged.
  • Android volume keys remain available to Android, while supported shutter, media, and external-switch keys continue to activate scanning.
