# SHINE AAC v0.3.0

Android version code: 49

## Miss-tolerant scan escape ladder

- Row and item scanning now show the current pass and repeat each level twice
  by default, so one missed target does not immediately move the user away.
- Missing an item for two complete passes returns scanning to the same row,
  with a longer first-row opportunity and an explicit `Back to rows` status.
- Missing all rows for two complete passes stops automatic scanning. The board
  dims, no target remains highlighted, and the status says
  `Scanning stopped · Press switch to resume`.
- The first activation while stopped only resumes scanning from the first row;
  it cannot accidentally select content.
- Settings offer one, two, or three passes, plus continuous scanning. Two
  passes are the default and recommended behavior.
- The complete behavior and setting are available in English and Traditional
  Chinese.
- Demo mode now begins by intentionally missing two item passes, returning to
  rows, missing two row passes, visibly stopping, and issuing a wake-only
  activation before continuing with its communication examples.

## Safer, more useful Traditional Chinese suggestions

- First-symbol Zhuyin suggestions now use a conservative Taiwan conversation
  corpus signal to promote at most two high-value candidates. Later symbols,
  phonetic continuations, paging, repair, and deliberate full input keep their
  established behavior.
- A reviewed, generated sensitive-label policy softly demotes ten labels only
  when user intent is weak. The vocabulary remains available, and complete
  non-alias phonetic input preserves the source ranking.
