# SHINE AAC v0.2.43

Android version code: 46

## Easier-to-learn communication board

- Put all 37 Zhuyin symbols on the first layer in a stable seven-row sequence,
  so users no longer need `更多` to find a basic symbol.
- Removed Zhuyin symbols from recommendation rows when the same symbols are
  already visible in the static board, and kept unused suggestion cells out of
  scanning.
- Kept suggestion rows at four columns while allowing the fixed Zhuyin rows to
  use up to six large targets.
- Added consistent `功能` badges, icons, and command styling so `復原`, `清除`,
  and other actions are less likely to be mistaken for input words.
- Made `復原` restore the previous suggestion page as well as the message, so a
  missed candidate remains available for another attempt.
- Replaced the unexplained `Rows`, `First`, and `Symbols` header jargon with
  instructional `目前：選列` and `目前：選格` status text. The longer first-cell
  hold remains, but is no longer presented as a separate user action.
- Changed `Config` to a bordered `⚙ 設定` control so it is visually distinct
  from the non-interactive status text beside it.

## Speech and scanning

- `EN` is now announced as `英文` instead of being read as an ambiguous sound.
- Slowed the first-use scanning default to 1,800 ms with a 2,300 ms initial
  hold. Existing users' saved custom timing is preserved.

## Text export

- Renamed the setting to `匯出文字記錄` and added a guided completion dialog
  showing the actual saved filename.
- Added `開啟文字檔` after Android's Save As flow, so users can open the exact
  exported file without searching for its folder.
- Added clear browser feedback with `查看匯出內容`, and added a dedicated
  export section to the user guide.

## Verification

- Core quick tests and Web configuration unit tests: PASS.
- Source and packaged WebView end-to-end tests: PASS, including Android export
  success, direct open, cancellation/failure feedback, and browser export.
- Android unit tests, lint, debug assembly, and signed release builds: PASS.
- All 103 frozen communication tasks remain reachable. The frozen scan-time
  regression threshold does not pass because the safer first-use speed is
  intentionally slower; this tradeoff has not been hidden or re-baselined.

## Distribution

- Use the signed release APK for direct installation.
- Use the signed release AAB for Google Play; an AAB is not directly
  installable.
- This remains an early testing release and must not be the user's only or
  emergency communication method.
