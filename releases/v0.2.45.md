# SHINE AAC v0.2.45

Android version code: 48

## Paused-row clarity

- Replaced the heavy black review-hold rectangle with a calmer whole-row state:
  pale teal-gray tiles and a solid 3 px dark-teal perimeter.
- Removed the active-row tile outlines and frozen progress fill during review
  hold. The row remains visibly grouped without implying that scanning is still
  advancing.
- Kept the board geometry unchanged when the hold treatment appears or clears.
  One activation releases the hold without selecting a tile.

## Android layout consistency

- Android WebView text now follows the system font scale through the native
  `textZoom` setting, bounded from 50% to 200%.
- The native host consumes system-bar and display-cutout insets after applying
  them, preventing some vendor WebViews from reserving the same safe area a
  second time.
- Compact-phone status content uses a stable two-line arrangement so phase,
  voice, and Settings labels do not wrap character by character at larger text
  or display scaling.

## Scanning and demonstration behavior

- State-changing actions and returns from Settings consistently hold the first
  row for deliberate review before scanning resumes.
- Demo playback greedily accepts the longest visible continuation and uses a
  temporary faster scan cap without changing the user's saved accessibility
  timing.
- Zhuyin correction relies on the existing undo action, removing the redundant
  reselect command and its dedicated pronunciation asset.
