# SHINE AAC v0.3.1

Android version code: 50

## Optional block scanning

- Added an optional `Blocks, then rows and columns` scanning mode alongside
  the existing row/column mode.
- The communication board, word suggestions, and language layouts are shared
  unchanged between scanning modes. English and Traditional Chinese retain
  their independently optimized layouts.
- Block scanning uses four balanced row groups for the built-in boards. The
  selected block remains visibly outlined while its rows are scanned.
- A block containing one selectable row automatically advances to that row.
  A row containing one selectable item automatically activates that item,
  avoiding redundant switch actions.
- Auto Demo supports both scanning modes.

## Consistent English input

- English remains a four-column board; the Traditional Chinese six-column
  Zhuyin layout does not change the embedded or standalone English layout.
- The single fixed `I` key now remains in the frequency-ordered spelling area:
  `E T A O` followed by `I N S R`.
- That one key enters the pronoun `I ` at a word boundary and lowercase `i`
  while spelling inside a word.
- One-character English predictions are excluded, so the fixed alphabet is
  not duplicated in the suggestion rows.

## Interface and compatibility

- Pause and stopped-state labels are shorter to avoid clipping on phones.
- Existing default configurations migrate to the corrected English layout and
  new scan-mode setting. Custom boards and dictionaries remain unchanged.
- Android volume keys remain available to Android, while supported shutter,
  media, and external-switch keys continue to activate scanning.
