簡明操作說明｜繁體中文（台灣）

快速開始 開關掃描 常用按鈕 設定與相機 問題排除

快速開始

等待掃描框移動，再用單一開關確認目前的掃描項目。開關可以是觸碰溝通畫面任意位置、音量鍵、外接按鈕或眨眼。已選文字會出現在畫面最上方，完成後可由裝置朗讀。

  1. 選擇內容：使用掃描依序選擇常用詞、注音或候選字詞。
  2. 確認文字：查看畫面最上方的訊息欄。
  3. 說出訊息：選擇「說」，由裝置朗讀完整訊息。

單一開關掃描

可將整個溝通畫面當作大型觸碰開關，也可使用音量鍵、外接按鈕或相機眨眼。操作分成「選整列」和「選列內格子」兩步。

每次選擇的步驟

  1. 等待青綠色框移到目標所在的整列。
  2. 觸碰溝通畫面任意位置、按一次音量鍵或外接按鈕；使用相機輸入時，完成一次有效長眨眼。
  3. 掃描會改成在該列內逐格移動。
  4. 框移到目標格子時，再啟動一次。
觸碰畫面是「開關」，不是直接點選。
在 AAC 溝通主畫面，無論觸碰哪個位置，都只會啟動青綠色掃描框目前所在的列或格子，不會直接選擇手指下的內容。「Config」和設定頁面才是供協助者直接操作的控制項目。

組合並說出 AAC 訊息

  1. 要快速表達需求時，掃描並選擇「喝水」、「吃飯」、「廁所」、「休息」等常用詞。
  2. 要輸入其他內容時，依序選擇注音，再從候選格選擇正確的字或詞；選擇「更多」可查看下一頁候選詞。
  3. 在畫面上方確認完整訊息。需要修正時，選擇「刪」、「清除」或「復原」。
  4. 訊息完成後選擇「說」，由裝置替使用者朗讀。

候選詞更新後

如果啟用了 Hold after suggestion changes，候選詞更新後會暫停。先啟動一次恢復掃描，再依照上面的兩步選擇。

音量鍵沒有作用？
到「Config」確認 Switch input 是 Phone/external buttons，並按「Save」。

常用按鈕

這些按鈕不會加入一般文字，而是執行操作。

說朗讀目前完整訊息。
刪刪除最後一個字或符號。
清除清空目前訊息。
復原回到上一次訊息狀態。
更多顯示下一頁候選字詞。
EN開啟英文輸入格。
Audio／Silent切換掃描提示音。
Config開啟設定、測試與匯出。

設定、相機輸入與文字匯出

在主畫面選擇「Config」。修改後要選擇「Save」，「Cancel」則放棄本次修改。

調整開關掃描

  1. 先用 Scan preset 選擇預設速度。
  2. 需要微調時，再改 Switch speed ms；數字越大，掃描越慢。
  3. 選擇 Input test，確認按鈕或感應輸入穩定。
  4. 選擇 Save 儲存。

設定相機眨眼輸入

  1. 在 Switch input 選擇相機長眨眼，或按鈕與相機並用。
  2. 選擇 Camera setup 並允許相機權限。
  3. 固定裝置位置，讓臉部和雙眼清楚出現在預覽中。
  4. 選擇 Start setup，再用 Test blink 測試。
  5. 確認穩定後選擇 Done，回設定頁按 Save。

文字紀錄與匯出

訊息歷史只儲存在裝置內。選擇 Export text 後，再從 Android 分享選單選擇目的地。只有在你主動匯出時，文字才會交給所選的其他應用程式。

版本與基本資訊

選擇 App info 可查看目前版本、資料處理方式、隱私權政策與支援連結。回報問題時請一併提供版本號碼。

常見問題排除

按音量鍵只改變音量，沒有選擇格子

開啟「Config」，把 Switch input 設為 Phone/external buttons 或按鈕與相機並用，然後選擇「Save」。

沒有語音或掃描提示音
  • 確認媒體音量不是零。
  • 主畫面顯示「Silent」時，選擇它切回 Audio。
  • 在 Config 檢查 Voice while scanning 和 Voice on activation。
相機找不到臉或眨眼不穩定
  • 確認光線充足、鏡頭乾淨，臉部不要超出預覽。
  • 固定手機或平板，不要手持晃動。
  • 重新執行 Camera setup，調整長眨眼時間和相機縮放。
  • 仍不穩定時，先改用實體按鈕。
回報問題時要提供什麼？

請提供裝置型號、Android 版本、App info 中的版本號碼、操作方式、發生步驟，以及不含敏感文字的畫面截圖。請勿在公開頁面張貼個人或健康資訊。

使用提醒：我想說 SayToMe AAC 目前是早期測試中的溝通輔助工具。它不能取代專業 AAC 評估、語言治療、醫療照護或可靠的緊急溝通方式。
