# SHINE AAC v0.2.40

Android version code: 43

## Google Play Internal testing build

This release supersedes v0.2.39 and includes a signed Android App Bundle for Google Play Internal testing.

Upload `shine-aac-v0.2.40-code43-release.aab` to Play Console. Do not upload the superseded code-42 bundle. The AAB is not directly installable; use Google Play Internal testing to distribute it.

## Fixed

- Upgrades from code 41 or code 42 now compact legacy per-input text-history snapshots into final text-area session lines before export.
- The reported 47-line Zhuyin/English history sequence now exports exactly two lines: `聽 podcast 新資料夾` and `冰紅茶少冰不要太甜`.
- Candidate commits, deletion, and undo branches remain within the current history line.
- Explicit `CLR`, demo reset, and configuration reset/save boundaries remain separate lines even when consecutive messages share text.

## Retained from v0.2.39

- Android back gestures navigate to the previous app page before exiting from the root board.
- Export text uses Android's system Save As picker and writes a UTF-8 `.txt` file.
- Current edits update one live line rather than creating new snapshots.
