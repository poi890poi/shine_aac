# SHINE AAC v0.2.41

Android version code: 44

## Google Play Internal testing build

This release supersedes v0.2.40 and updates the app to target Android 16 / API level 36.

Upload `shine-aac-v0.2.41-code44-release.aab` to Play Console. Do not upload the superseded code-43 bundle. An AAB is not directly installable; Google Play generates device APKs for Internal testers.

## Changed

- Raised `compileSdk` and `targetSdk` to API 36 for the release app and diagnostic app; the shared Android input library also compiles against API 36.
- Upgraded the supported build toolchain to Android Gradle Plugin 8.10.1 and Gradle 8.11.1.
- Updated clean-machine SDK setup to install Android SDK Platform 36 and Build Tools 36.0.0.
- Corrected Windows SDK-path escaping in setup, debug-build, and Play-bundle scripts so newer lint accepts generated `local.properties` files.

## Retained behavior

- Android back gestures navigate to the prior app page before leaving the root communication board.
- Export uses Android's Save As document picker and writes UTF-8 text with one final line per text-area session.
- Fundamental Zhuyin continuations remain ahead of speculative glyphs/words, and demos can reach displaced continuations through bounded `更多` pages.
- Multi-symbol Zhuyin buffers retain mistake-repair and `重選` behavior.
