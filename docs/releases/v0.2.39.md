# SHINE AAC v0.2.39

Android version code: 42

## Google Play Internal testing build

This release includes a signed Android App Bundle for Google Play Internal testing.

Upload `shine-aac-v0.2.39-code42-release.aab` to Play Console. The AAB is not directly installable; use Google Play Internal testing to distribute it.

## Fixed

- Android back gestures now return App Info and Input Test to Configuration, then Configuration to the communication board. Back exits only from the root board.
- Text history now updates one live line while the current text area is edited instead of adding a snapshot for every symbol.
- `CLR`, demo reset, and configuration reset/save close the current history line; the next non-empty text starts a new line.
- Export text now opens Android's system Save As picker and writes a UTF-8 `.txt` file instead of opening a share flow.
- Exported history contains one plain-text entry per line without diagnostic metadata.
- Existing version-1 text-history snapshots remain available after migration.
