# SHINE AAC v0.3.2

Android version code: 51

## Scanning efficiency and clarity

- The first target in a scan group uses a longer 2400 ms hold by default,
  including the first row after a block is selected.
- Block and row progress moves downward; individual cells and automatic
  suggestion-page previews move horizontally.
- Optional automatic `更多` paging previews each bounded candidate page and
  stops after two passes. Activating during the preview now selects the visible
  four-row page as the active block and immediately begins row scanning inside
  it instead of restarting top-level block scanning.
- Optional first-pass Zhuyin deferral temporarily skips source-impossible
  continuations while leaving them visibly available on the second pass.

## Taiwan Mandarin input

- Common-glyph coverage is protected by independent frequency evidence.
- Optional tone selection provides a final fallback for uncommon glyphs.
- Context-aware intent prediction combines recent committed glyphs with one or
  two incomplete Zhuyin symbols to reduce selections without limiting phrase
  construction from individual glyphs.

## English board

- Both previously empty cells are now useful: `LIKE` occupies the old clear
  position, `?` stays in the lower spelling rows, and `CLR` moves to the
  bottom-right position shared with the Taiwan Mandarin board.
- Question-mark spacing closes the preceding word directly (`help? `).
- The communication benchmark improves the two LIKE cases without regressions.

This is an early testing release and must not be the user's only or emergency
communication method.
