## Improved

- Invalid Zhuyin buffers now offer tolerant whole-buffer repairs without assuming only the last symbol can be wrong.
- Multi-symbol Zhuyin buffers offer `重選`, which clears only the pending phonetic buffer while preserving committed message text.
- Dense and sparse Zhuyin combinations allocate candidate and continuation space adaptively without increasing measured activations or `更多` use.
- Demo activation resets the current draft and scanner state before playback.
- Communication efficiency changes are checked against a frozen paired baseline with aggregate, P90, function-group, reachability, and bounded-paging gates.
