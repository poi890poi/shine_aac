# SHINE AAC v0.3.4

Android version code: 58

## Communication after speech

- Added an optional replay-control view that locks a message after it is
  spoken and offers three large scan targets: replay, next message, and edit.
- Added an optional conversation display that enlarges the current spoken
  message and shows up to two earlier messages that were actually spoken.
- Kept the original continue-input behavior as the default.

## Camera gesture switch

- Added cheek twitch as a camera-switch gesture alongside long blink, including
  personalized calibration, configurable hold duration, live setup feedback,
  and persistent settings.
- Improved cheek analysis performance and lifecycle handling so the continuous
  input path remains responsive and releases camera resources safely.
- Expanded the live camera preview while keeping setup controls reachable, and
  consolidated related labels and controls to use phone space efficiently.

## Camera setup and input reliability

- Restored normal camera zoom control and selectable built-in cameras. USB/UVC
  external-camera support is not part of this release.
- Preserved the Settings workflow across activity and process lifecycle changes;
  setup completion returns to the expected screen without losing edits.
- Hardened blink classification around dropped frames and calibration quality,
  and kept early native switch events until the WebView is ready.

## Configuration and accessibility

- Added complete light and dark high-contrast presets and removed fixed light
  surfaces that broke dark themes.
- Improved configuration spacing, touch-target naming, reset confirmation,
  camera-input wording, localization, and behavior at large font sizes.
- Added systematic structural layout audits for clipping, obscured actions,
  oversized gaps, undersized controls, and unstable camera-preview geometry.

## Documentation

- Updated the Traditional Chinese quick-start guide for 0.3.4.
- Added dedicated pages for camera gesture setup and advanced scanning,
  timing, speech, input, contrast, and content settings.

## Licensing

## Distribution

- Use the signed AAB only for Google Play; an AAB is not directly installable.
- Direct installations use the versioned debug APK produced by the host release
  process. Google Play must not receive that debug APK.
