# SHINE AAC v0.3.4

Android version code: 58

## Cheek-twitch camera switch

- Added cheek twitch as a camera-switch gesture alongside long blink, including
  personalized calibration, configurable hold duration, live setup feedback,
  and persistent settings.
- Improved cheek analysis performance and lifecycle handling so the continuous
  input path remains responsive and releases camera resources safely.

## Camera setup and input reliability

- Restored the compact, verified camera-setup layout and normal camera zoom
  control, with selectable front cameras for future external-camera use.
- Preserved the Settings workflow across activity and process lifecycle changes;
  setup completion returns to the expected screen without losing edits.
- Hardened blink classification around dropped frames and calibration quality,
  and kept early native switch events until the WebView is ready.
