# SHINE AAC v0.4.0

Android version code: 59

## USB UVC camera support

- Added direct USB UVC webcam discovery and capture on Android USB Host/OTG
  devices, alongside built-in and Camera2-exposed external cameras.
- Added per-device USB permission handling, reconnect/detach lifecycle cleanup,
  stable source selection, and fallback when a reconnected camera receives a
  different USB bus address.
- Added common MJPEG/YUYV frame-size selection and on-device frame conversion
  for the existing long-blink and cheek-twitch detectors.
- Packaged native UVC support for arm64-v8a, armeabi-v7a, x86, and x86_64 with
  current Android native-page alignment.

## Native helper settings

- Added a native Android Settings surface for routine helper configuration and
  a separate Advanced timing page for less common scanning controls.
- Preserved the shared WebView configuration store and migration path so native
  settings and the communication board use the same values.
- Added localized labels, summaries, About information, and safe navigation
  back to the communication board.

## Existing 0.3.4 improvements included

- Includes calibrated cheek-twitch and long-blink input, expanded stable camera
  preview, speech replay/conversation modes, contrast presets, layout fixes,
  safer reset behavior, and Apache License 2.0 licensing.

## Documentation

- Added dedicated guides for USB UVC cameras, camera gestures, advanced
  settings, and Android speech download/offline setup.

## Distribution

- Direct installations use the versioned debug APK.
- Google Play uses only the signed AAB; do not upload the debug APK to Play.
