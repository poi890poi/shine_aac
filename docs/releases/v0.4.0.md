# SHINE AAC v0.4.0

Android version code: 60

## Camera access and paused idle

- Added optional **Hold to advance** (`持續連選`). One sustained calibrated
  camera gesture can select the current block, the first row, and the first
  cell. It is capped at that leaf and cannot repeat until the user releases.
- Added optional **Idle timeout** (`待機時間`) with Off, 1, 5, 15, and 30
  minute choices. The countdown runs only after scanning has stopped.
- Idle keeps the app and optical wake path available while dimming the app
  window and reducing camera capture, analysis, and status work. The first
  optical activation exits idle and resumes scanning without selecting content.
- Both options default to Off so an update does not silently change an existing
  access method.

## USB UVC camera support

- Added direct USB UVC webcam discovery and capture on Android USB Host/OTG
  devices, alongside built-in and Camera2-exposed external cameras.
- Added per-device USB permission handling, reconnect/detach lifecycle cleanup,
  stable source selection, and fallback when a reconnected camera receives a
  different USB bus address.
- Added common MJPEG/YUYV frame-size selection and on-device frame conversion
  for the existing long-blink and cheek-twitch detectors.
- Packaged native UVC support for arm64-v8a, armeabi-v7a, x86, and x86_64 with
  current Android native-page alignment.

## Native helper settings

- Added a native Android Settings surface for routine helper configuration and
  a separate Advanced timing page for less common scanning controls.
- Preserved the shared WebView configuration store and migration path so native
  settings and the communication board use the same values.
- Added localized labels, summaries, About information, and safe navigation
  back to the communication board.

## Offline resources

- Added a native Offline resources page under Data and support and registered
  it as Android's app-specific storage management activity.
- Added a WorkManager-backed, versioned download path for cheek-model updates
  with size and SHA-256 verification before installation.
- Kept the verified cheek model bundled in 0.4.0 as an offline fallback so an
  existing camera-switch user is not disabled by an offline app update.
- The detector prefers a verified downloaded update and safely falls back to
  the bundled model; downloaded updates can be removed independently of user
  calibration.

## Existing 0.3.4 improvements included

- Includes calibrated cheek-twitch and long-blink input, expanded stable camera
  preview, speech replay/conversation modes, contrast presets, layout fixes,
  safer reset behavior, and Apache License 2.0 licensing.

## Documentation

- Added dedicated guides for USB UVC cameras, camera gestures, advanced
  settings, Android speech download/offline setup, and
  [offline resource management](../OFFLINE_RESOURCES.md).

## Distribution

- Direct installations use the versioned debug APK.
- Google Play uses only the signed AAB; do not upload the debug APK to Play.
