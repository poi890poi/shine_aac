# SHINE AAC v0.2.44

Android version code: 47

## English dictionary and ranking

- Replaced the 280-entry handcrafted English suggestion vocabulary with 27,717
  entries generated from the pinned AOSP LatinIME en-US frequency model.
- Prefix completions and word-boundary suggestions now preserve AOSP unigram
  frequency order. Removed the app-specific AAC priority tiers and handcrafted
  word-to-word transition lists.
- The retained source threshold is frequency 70, the highest round cutoff that
  still supplies at least four source-ranked candidates for every initial
  letter. Frequency-zero and unsupported token forms remain excluded.
- Development-time generation removes 6,534 mechanically simple `+s` forms
  when the exact base word is also retained. A small explicit exception set
  preserves suffix collisions and non-plurals such as `his`, `its`, `does`,
  `news`, `species`, and possessive pronouns.
- Existing built-in English dictionaries migrate through internal configuration
  version 23; custom dictionaries retain their user-entered order. Android
  version name/code remain 0.2.44/47.
- Long English candidates keep the same font and label spacing as ordinary word
  keys. They span two or more columns when needed, remain a single scanner
  target, and use a taller wrapped full row only when the whole display width is
  still insufficient at large system text sizes.
- The English and zh-TW English boards always reserve two suggestion rows, so
  scanner-row positions do not move while spelling or committing a word.
- If a wide candidate cannot fit the remaining columns, the highest-ranked
  later candidate that does fit fills the gap. The deferred wide candidate is
  reconsidered first on the following row, avoiding preventable empty cells.

## Accessibility scaling correction

- Android WebView text now follows the system font-size preference instead of
  being fixed at 100%, up to Android's 200% maximum.
- Function keys share a strong border, fill, icon, semantic name, and consistent
  concise zh-TW labels: `英文`, `朗讀`, and `清除`. Contextual `復原` now handles correction without a separate built-in `刪除` key. The optional `功能`
  corner cue collapses on narrow phones so it cannot cover the action label.
- Fixed AAC-cell labels are fitted from measured space only when wrapping cannot
  fit them, with a 10 CSS-pixel minimum instead of the previous 4-pixel floor.
- Camera setup keeps `開始`, `測試`, and `完成` visible in a fixed
  horizontal action bar. Hold and zoom controls scroll independently with a
  persistent scrollbar.
- Camera title, status, metrics, and action labels can wrap instead of being
  silently ellipsized at large font sizes.

## zh-TW interaction and locale correction

- The zh-TW English board now reuses the English suggestion engine. Partial
  spelling can be completed from the top suggestion row, with localized
  `復原` and `空格` controls.
- Closing the English board removes automatic boundary whitespace, so mixed
  messages and the demo produce compact text such as `聽podcast新資料夾` without
  spending switch selections on spaces.
- The zh-TW web configuration, app information, input test, camera status, and
  native camera calibration UI now use Traditional Chinese labels and feedback.
- Existing code-47 configurations using `EN`, `說`, or `刪` migrate in place to
  `英文` and `朗讀`; the Android version code remains 47.

## Regression prevention

- Default row scanning and every cell now use the same 1800 ms interval. The
  former hidden 2300 ms first-cell exception migrates to the consistent default;
  the explicitly named first-cell-support preset remains available.
- Reset and Demo initialization now finish board measurement before the visible
  scan clock starts. Removed the separate zero-delay precomputation timer and
  two-frame scan startup chain that could produce startup-only pauses.
- Suggestion-review hold after input remains opt-in and legacy default-on
  configurations migrate off. Initial launch and Reset deliberately hold the
  first row with a dashed cue; one activation releases that hold and starts
  normal scanning without selecting a tile.
- Added a non-polling timing probe for Reset, row activation, successive cells,
  and word selection. Visible scan restarts must remain within 80 ms and scan
  deadline drift within 50 ms in both source and packaged-WebView runs.
- Added million-entry computational acceptance: empty English reads 8
  candidates, empty zh-TW reads 45, and an adversarial cold English prefix may
  make one preparation pass but performs zero corpus reads while scanning.
- Configured zh-TW suggestions are now consumed lazily, preventing an oversized
  custom dictionary from being materialized before its bounded 45-result UI.
- Added geometry assertions for adaptive function-label/icon presentation on
  oversized-text and dense 13-row Zhuyin layouts.
- Added core and browser coverage for shared English completions, localized
  controls, and trimming the English-to-Zhuyin boundary space.
- Added unit coverage for Android-to-WebView font zoom at 85%, 100%, 130%, and
  200%.
- Added `docs/TEXT_SCALING_POLICY.md`; releases must test default and 200% font
  with default and larger display size, including the combined worst case on a
  target Samsung device.
