# SHINE AAC v0.4.2

Android version code: 62

## Communication and scanning

- Filtered three-layer Zhuyin scanning now forms compact contiguous blocks and avoids
  spanning large inactive gaps when the configured block budget can preserve them.
- After a missed first pass, deferred Zhuyin cells keep their dashed inactive style
  while row and block progress remains visually continuous.

## Settings and camera setup

- Android speech-voice selection now lists only Chinese and English voices supported
  by SHINE's language profiles, alongside the built-in and system-default choices.
- Camera Setup requests portrait orientation on compact devices so rotation does not
  recreate the preview while framing and calibration geometry are being established.
  Large-screen Android devices retain the platform's adaptive-orientation behavior.

## Test infrastructure

- The optical rig can use a second Android device as a pixel-controlled presenter,
  with explicit device roles, paint acknowledgements, and camera-decoded atlas proof.
  This changes testing only and does not alter SHINE's runtime camera or scanning
  behavior.

## Safety scope

- This remains an early test release. It must not be the user's only or emergency
  communication method.
- Helpers should calibrate and verify the chosen access method with each user and
  device before routine use.
