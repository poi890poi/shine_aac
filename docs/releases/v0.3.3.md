# SHINE AAC v0.3.3

Android version code: 56

## Hardware switch input

- The existing switch-input selector adds `Buttons — volume activates`. This
  mode accepts volume-up and volume-down as activation events for devices such
  as Bluetooth shutter remotes that present themselves as volume controls.
- `Buttons — keep volume control` remains the default and preserves normal
  Android volume adjustment while supporting non-volume hardware keys.
- Camera-focus keys join the already supported camera, media, and external
  controller keys.
- Switching between the two modes takes effect immediately through the existing
  selector; no extra checkbox is added.

## Camera switch input

- Auto-calibrated blink-detection parameters are now shared between live
  detection and the recalibration screen, so a recalibration run and normal
  use agree on the same thresholds.
- Fixed camera blink detection not correctly re-arming after an activation,
  which could leave the switch unresponsive until the app was restarted.
- Hardened camera setup and raised the default long-blink threshold.
- Reduced latency in live blink detection.
- Camera switch input can now use either the built-in or an external camera.
- Scanning now pauses automatically when the app leaves the foreground and
  resumes when it returns.
