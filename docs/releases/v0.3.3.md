# SHINE AAC v0.3.3

Android version code: 57

## Hardware switch input

- The existing switch-input selector adds `Buttons — volume activates`. This
  mode accepts volume-up and volume-down as activation events for devices such
  as Bluetooth shutter remotes that present themselves as volume controls.
- `Buttons — keep volume control` remains the default and preserves normal
  Android volume adjustment while supporting non-volume hardware keys.
- Camera-focus keys join the already supported camera, media, and external
  controller keys.
- Switching between the two modes takes effect immediately through the existing
  selector; no extra checkbox is added.

## Camera setup fixes (code 57)

- Fixed a critical bug where finishing camera setup (`完成`) could land on the
  main scanning board instead of returning to Settings, discarding any unsaved
  settings edits, and could leave blink activation unresponsive (a long blink
  registered its confirmation tone but did not switch) until the app was
  force-restarted. Settings now persist a recovery draft before opening camera
  setup and restore Settings, with the in-progress field values, on the next
  app start if the round trip through camera setup caused the app process to
  be recreated. Native input events are now queued and delivered once the
  WebView has finished loading instead of being silently dropped if a switch
  activation arrives before the page is ready.
- Removed the separate "測試" (Test) button in camera setup. It duplicated the
  screen's existing always-on live blink preview and feedback; the preview
  alone now covers verifying setup.
- Scan timing no longer changes automatically based on the selected switch
  input. Previously, enabling a camera switch profile silently forced the
  camera long-blink timing preset at runtime regardless of what the "Scan
  preset" setting displayed. The "Scan preset" selection is now the single,
  honest source of truth for scan timing in all switch-input modes; pick the
  "Camera long blink" preset explicitly if desired.

## Display

- Added optional higher-contrast display presets ("High contrast (light)" and
  "High contrast (dark)") alongside the default theme, for displays with low
  or biased contrast/saturation. Selectable from Settings and previewed live
  before saving.
- The camera status indicator no longer adds its own layout row/line on
  narrow phones or in the wide landscape layout. It now sits inline next to
  the voice status label, so enabling or disabling it does not shift the rest
  of the top panel.

## Verification

- `npm run test:core`: core regression suite.
- `npm run test:web:packaged`: packaged WebView end-to-end suite.
- Android hardware-key and blink-detection/blink-classifier unit coverage.
- Signed release APK and Play AAB built and checksummed.

## Distribution

- Use the signed release APK for direct installation.
- Use the signed release AAB for Google Play; an AAB is not directly
  installable.
