USB UVC 外接相機

在支援 USB Host／OTG 的 Android 裝置上，以外接網路攝影機辨識長眨眼或臉頰動作。

每一組硬體都要實測。

UVC 只代表通用的 USB 影像類別，不保證每一台相機、OTG 轉接器、集線器與 Android 裝置都能搭配。請保留內建相機或實體開關作為備用方式。

準備硬體

  • 支援 USB Host／OTG 的 Android 手機或平板。
  • 標示支援 UVC 的 USB 網路攝影機。
  • 正確的 USB-C／Micro-USB OTG 轉接器；相機耗電較高時使用有外接電源的 USB 集線器。
  • 穩固的手機與相機支架，讓臉部維持在固定位置。

連接與選擇

  1. 先固定裝置與外接相機，再接上 OTG 轉接器或有供電的集線器。
  2. 開啟「設定」，把「開關輸入」設為「相機動作」或「按鍵＋相機動作」。
  3. 選擇「相機設定」。第一次使用相機功能時允許 Android 相機權限。
  4. 使用「下一個相機」切換，直到相機標示顯示 USB／UVC 且預覽來自外接相機。
  5. Android 顯示 USB 裝置權限視窗時選擇允許。App 只有在選到 USB 相機後才會要求這項裝置權限。
  6. 若拔除後重新接上，相機的 USB 位址可能改變；App 會嘗試尋找相同類型的 UVC 裝置，但仍要確認預覽來源。
隱私與網路

USB 與內建相機影像都只在 Android 裝置上由內建的 MediaPipe 模型分析，不會由我想說儲存或上傳。網路只用於使用者主動選擇的資源更新，不會上傳相機畫面或 AAC 訊息。

校正與驗證

  1. 調整實際相機位置與正常縮放，讓臉部置中並完整顯示雙眼、鼻子與臉頰。
  2. 選擇長眨眼或臉頰動作，依提示完成新的個人設定。不要直接沿用另一個相機角度的結果。
  3. 在相機設定頁測試數次有意動作，並自然休息至少一分鐘觀察誤觸。
  4. 回到溝通板，以正常掃描速度完成一段完整訊息及朗讀；短時間連續觸發測試不能取代這一步。
  5. 重新插拔 USB 相機後，再次確認來源、取景、校正表現與長時間穩定性。

問題排除

相機清單沒有 USB／UVC
  • 確認 Android 裝置支援 USB Host／OTG，並嘗試品質良好的 OTG 轉接器。
  • 若相機沒有亮燈或反覆連線，改用有外接電源的 USB 集線器。
  • 拔除後重新接上，再回到相機設定重新切換相機。
  • 確認相機明確支援 UVC；需要專用 Windows 驅動的相機通常不適用。
已選 USB，但沒有影像或影像中斷
  • 確認已允許 Android 的 USB 裝置權限；拒絕後可重新拔插再選一次。
  • 降低同一集線器上的其他 USB 負載，並檢查接頭是否鬆動。
  • 改試可提供穩定電力的集線器；USB 頻寬或供電不足都可能使串流中斷。
  • 若該相機提供特殊格式而無法開啟，改用常見支援 640×480 MJPEG 或 YUYV 的 UVC 相機。
預覽正常，但動作不穩定

先固定外接相機、改善正面光線、重新調整正常縮放，再為此相機角度重新校正。請同時驗證有意動作、自然休息與完整正常使用流程。

安全提醒

外接相機可能因接頭、供電或裝置休眠而中斷。相機動作輸入不能作為唯一或緊急溝通方式。
