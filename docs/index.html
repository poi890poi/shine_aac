快速開始

使用者可用一個能穩定操作的外接按鈕控制掃描。常見的低成本選擇是藍牙自拍快門或藍牙遙控按鈕；第一次使用前，請由協助者完成 Android 藍牙配對與輸入測試。0.3.1 可選擇原本的「列、格」或新的「區塊、列、格」掃描方式。

  1. 準備按鈕：協助者先確認每按一次，App 只啟動一次。
  2. 選整列：框移到目標所在列時，按一次。
  3. 選格子：框移到目標格子時，再按一次。
  4. 說出訊息：重複選擇內容，完成後選擇「朗讀」。

單一開關掃描

主要操作方式是外接按鈕，例如藍牙自拍快門、藍牙遙控按鈕或相容的輔具開關介面。尚未接上按鈕時，協助者也可觸碰溝通畫面任意位置來練習。預設操作分成「選整列」和「選列內格子」兩步；協助者也可在設定改用「區塊、列、格」三層掃描。

每次選擇的步驟

設定鍵左側的狀態會顯示「目前：選列」或「目前：選格」，提示現在要選整列還是列內格子；這段文字只是狀態提示，不是可輸入的字詞或按鈕。第一格雖然會停留久一點，畫面不再另外顯示難懂的「First」。

  1. 等待青綠色框移到目標所在的整列。
  2. 按一次外接按鈕；使用相機輸入時，完成一次有效長眨眼。
  3. 掃描會改成在該列內逐格移動。
  4. 框移到目標格子時，再啟動一次。

區塊、列、格掃描

這是 0.3.1 新增的選用模式，適合覺得逐列等待太久的使用者。它只改變掃描路徑，不會改變注音、英文、候選字詞或格子位置。

  1. 紫色框會依序框住數列形成的區塊；目標位於該區塊時啟動一次。
  2. 選定區塊後，青綠色框只掃描區塊內的列；移到目標列時再啟動一次。紫色外框會保留，方便辨認目前範圍。
  3. 最後在該列內選擇目標格子。
  4. 如果區塊只有一個可選列，或列內只有一個可選格，App 會自動進入下一層或直接啟動，不要求多按一次。
觸碰畫面是「開關」，不是直接點選。
在 AAC 溝通主畫面，無論觸碰哪個位置，都只會啟動青綠色掃描框目前所在的列或格子，不會直接選擇手指下的內容。觸碰操作適合協助者設定或陪同練習；日常溝通請使用使用者能穩定操作的按鈕。「設定」和設定頁面由協助者直接操作。

組合並說出 AAC 訊息

  1. 要快速表達需求時，掃描並選擇「喝水」、「吃飯」、「廁所」、「休息」等常用詞。
  2. 37 個注音符號都固定在主畫面，依熟悉的注音順序排成七列，每列最多六格。依序選擇注音後，再從上方候選格選擇正確的字或詞；「更多」只會顯示下一頁候選字詞。
  3. 有藍色或紅色底色的格子是操作鍵，不會當成文字輸入。需要修正時，選擇候選列中的「復原」回到上一步；它可以撤銷單一字母、注音、整個候選字詞或清除操作。
  4. 如果誤選候選字詞，選擇「復原」會回到誤選前的同一頁候選詞，方便重新選擇漏掉的項目。
  5. 訊息完成後選擇「朗讀」，由裝置替使用者朗讀。

候選詞更新後

如果啟用了候選字詞更新後暫停，候選詞更新後會暫停。先啟動一次恢復掃描，再依照上面的兩步選擇。

外接按鈕沒有作用？
到「設定」確認開關輸入是手機／外接按鍵，按「儲存」，再用輸入測試測試。

常用按鈕

主畫面上有深色外框、底色及圖示的格子不會加入一般文字，而是執行操作。窄螢幕會隱藏角落小標，保留完整的按鍵名稱。

朗讀朗讀目前完整訊息。
刪除刪除最後一個字或符號。
清除清空目前訊息。
復原回到上一次訊息狀態；若剛才誤選候選詞，也會回到原本的候選頁。
更多顯示下一頁候選字詞。
英文開啟英文拼字及候選字詞；回到注音時會自動移除中英文邊界上不必要的空格。
⚙ 設定開啟設定、測試與匯出；有外框與底色，表示它是可按的控制鍵。

必要設定

一般使用可直接從主畫面開始。需要調整掃描、輸入或語音時，再選擇「⚙ 設定」。大多數修改要按「儲存」才會儲存。

設定外接按鈕

  1. 在 Android 設定中配對藍牙自拍快門、藍牙遙控按鈕或其他相容的開關介面。
  2. 開啟設定，把開關輸入設為手機／外接按鍵，再按儲存。
  3. 重新開啟設定，選擇輸入測試。
  4. 請使用者用平常的姿勢按數次，確認每按一次只記錄一次，沒有漏按或連續觸發。

不同藍牙快門送出的按鍵訊號可能不同。若輸入測試完全沒有反應，請改用其他相容按鈕或開關介面。

調整開關掃描

  1. 用掃描方式選擇「列、格」或「區塊、列、格」。兩種方式使用完全相同的溝通版面與候選字詞。
  2. 先用掃描速度預設選擇預設速度。
  3. 需要微調時，再改掃描間隔（毫秒）；數字越大，掃描越慢。
  4. 選擇輸入測試，確認按鈕或感應輸入穩定。
  5. 選擇儲存。

設定相機眨眼輸入

  1. 在開關輸入選擇相機長眨眼，或按鍵＋相機。
  2. 選擇相機設定並允許相機權限。
  3. 固定裝置位置，讓臉部和雙眼清楚出現在預覽中。
  4. 選擇開始，再用測試測試。
  5. 確認穩定後選擇完成，回設定頁按儲存。

朗讀語音需要調整時

  1. 在語音區選擇語音；若版本顯示台灣語音，請選擇該項目。
  2. 選擇已下載的台灣中文語音；有播放鍵時，先按播放鍵試聽。
  3. 若沒有合適的語音，選擇管理語音，依 Android 畫面下載語音資料。

完整步驟請見下方的語音下載與離線設定。

版本與基本資訊

選擇關於本程式可查看目前版本、資料處理方式、隱私權政策與支援連結。回報問題時請一併提供版本號碼。

語音下載與離線設定

一般訊息由 Android 的文字轉語音（TTS）引擎朗讀。第一次使用前，建議由協助者下載所需語言的語音資料並完成離線測試；不同品牌手機、Android 版本及語音引擎的選單名稱可能稍有不同。

下載並選用語音

  1. 先連上 Wi-Fi，並確認裝置有足夠的儲存空間。
  2. 在主畫面選擇 ⚙ 設定，到語音區選擇管理語音。Android 會開啟目前使用中的文字轉語音設定或語音資料安裝畫面。
  3. 確認已選擇要使用的語音引擎，再選擇安裝語音資料、安裝語音數據或名稱相近的選項。有些裝置要先按語音引擎旁的齒輪。
  4. 下載中文（台灣）／繁體中文（台灣）／zh-TW。若會使用英文版面，也下載英文（美國）／en-US。
  5. 下載完成後返回「我想說」，重新開啟設定。選擇語音（舊版介面為台灣語音），再選擇剛下載的語音或Android 系統預設。
  6. 若畫面提供播放鍵，先試聽；接著回主畫面輸入短句並選擇朗讀，確認音量、語言和發音。
需要離線使用？
請選擇標示「已下載」或未標示「需要網路」的語音。完成設定後關閉 Wi-Fi 與行動網路，再朗讀一次短句；只有實際通過這項測試，才能確認該裝置與語音可離線使用。

畫面上的語音類型

  • 內建台灣華語語音：內附教育部人聲注音，用於注音符號；一般中文字句仍交由裝置的 Android 語音朗讀。
  • Android 系統預設：由目前的 Android 語音引擎決定實際聲音；更換系統引擎或系統預設語音後，聲音可能改變。
  • 已下載／可用：通常可離線使用，但仍應依上方步驟實測。
  • 需要網路／線上語音：朗讀時需要網路，資料處理由該語音服務供應者決定；不適合必須離線或網路不穩定的情境。
  • 可下載：先按下載圖示。若數秒後仍未開始，選擇開啟語音下載設定，在 Android 畫面完成安裝，返回 App 後再開啟語音清單。

設定前注意

  • 下載語音可能需要較多網路流量，建議使用 Wi-Fi。
  • 語音引擎、可用聲音、下載大小和資料處理方式由 Android 裝置及語音供應者決定，不是由本 App 提供。
  • Android 的文字轉語音輸出說明也列出選擇引擎、語言及安裝語音資料的一般步驟。

匯出並開啟文字記錄

App 會把每次完成的訊息保留在這台裝置內。需要交給家人、老師或治療師查看時，可由協助者主動匯出成 UTF-8 純文字檔；App 不會自動上傳或分享內容。

在 Android 裝置上

  1. 在主畫面選擇 ⚙ 設定。
  2. 選擇 匯出文字記錄。
  3. Android 會開啟「另存新檔」畫面。選擇資料夾，確認或修改檔名，再按 儲存。
  4. 回到 App 後，確認「文字已匯出」視窗顯示的實際檔名。
  5. 選擇 開啟文字檔，直接用裝置上的文字閱讀 App 查看內容。
儲存後找不到檔案？
先使用完成畫面中的「開啟文字檔」。如果裝置沒有可開啟純文字檔的 App，檔案仍已儲存在剛才選擇的資料夾，可稍後從 Android 的「檔案」App 開啟。

檔案內容與隱私

  • 檔案格式是 .txt；每次訊息一行，方便閱讀或另行整理。
  • 未選擇匯出時，訊息歷史只留在 App 的本機資料中。
  • 匯出只建立檔案，不會自動寄信、上傳雲端或複製到剪貼簿。
  • 文字可能包含私人或健康資訊。請由使用者或受信任的協助者選擇儲存位置與後續分享對象。

瀏覽器版本

在瀏覽器中選擇 匯出文字記錄 會下載文字檔。畫面也會提供 查看匯出內容，可立即確認本次匯出的文字。

常見問題排除

找不到某個注音符號

37 個注音符號都固定在主畫面的七列注音區，不需要選擇「更多」。位置依熟悉的注音順序固定；「更多」只切換候選字詞頁面。

藍牙快門或外接按鈕沒有作用
  • 確認按鈕已在 Android 藍牙設定中完成配對並顯示已連線。
  • 把開關輸入設為手機／外接按鍵或按鍵＋相機，再按儲存。
  • 進入輸入測試確認 App 是否收到按鈕訊號。
  • 若完全沒有反應，該按鈕可能未送出 App 支援的 Android 按鍵訊號，請改用其他相容裝置。
沒有語音或掃描提示音
  • 確認媒體音量不是零。
  • 主畫面的 語音：開／語音：關 是狀態顯示，不是按鈕。
  • 在設定頁開啟需要的選列時朗讀、選格時朗讀或選定後朗讀，再按儲存。
  • 到設定的語音區選擇管理語音，確認 Android 語音引擎已啟用並已安裝目前語言的語音資料。
  • 返回 App 後重新開啟設定，進入語音（舊版為台灣語音）選擇並試聽其他語音。
  • 若只在線上有聲音，請改選已下載且未標示「需要網路」的語音，並依離線設定步驟重新測試。
相機找不到臉或眨眼不穩定
  • 確認光線充足、鏡頭乾淨，臉部不要超出預覽。
  • 固定手機或平板，不要手持晃動。
  • 重新執行相機設定，調整長眨眼時間和相機縮放。
  • 仍不穩定時，先改用實體按鈕。
回報問題時要提供什麼？

請提供裝置型號、Android 版本、App info 中的版本號碼、操作方式、發生步驟，以及不含敏感文字的畫面截圖。請勿在公開頁面張貼個人或健康資訊。

使用提醒：我想說 SayToMe AAC 目前是早期測試中的溝通輔助工具。它不能取代專業 AAC 評估、語言治療、醫療照護或可靠的緊急溝通方式。
