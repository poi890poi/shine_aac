建議順序

先選輸入方式，再選掃描方式與速度預設，最後才微調時間。每次只改一類設定，使用同一組常用訊息比較速度、錯誤、疲勞與理解負擔。

可靠的調整方法

  1. 記下目前可完成的基準任務，例如「我要喝水」與一次修正。
  2. 選擇最接近需求的預設，不要一開始直接改毫秒數。
  3. 讓使用者完成同一組任務，記錄漏過、誤選、等待與疲勞。
  4. 一次只改一個變數；至少重複數次，避免把偶然成功當成改善。
  5. 選擇「儲存」後回到主畫面驗證。設定頁中的「取消」會捨棄尚未儲存的修改。

掃描方式與時間

列、格

先選整列，再選列內格子。步驟容易理解，適合作為初次設定的基準。

區塊、列、格

先選包含數列的區塊，再選列與格。目標列很多時可能縮短等待，但多一層判斷。應用實際任務比較，不應只以理論步數決定。

設定影響何時調整
掃描速度預設同時套用一組協調過的掃描與停留時間。所有使用者先從預設開始。
掃描間隔框在一般列或格停留的時間；數字越大越慢。經常錯過所有目標，或等待明顯過久。
第一列／第一格停留進入新層級後，第一個目標停留較久，讓使用者理解畫面變化。常在剛選列後錯過第一格。
選列取消等待選列後保留短暫取消機會；設為 0 會直接進入選格。常因連續誤觸進入錯誤列；一般使用保持預設。
輸入延遲補償把格子剛切換後極短時間內的啟動視為上一格。輸入裝置或動作有可重複的固定延遲。
離開前掃描次數錯過目標後，整組掃描重複幾輪才停止或返回。使用者需要更多觀察時間，或持續掃描造成疲勞。

「更多」候選頁與注音第一輪

「自動掃描更多頁面」會讓候選頁也加入單一開關掃描；適合無法由協助者換頁時使用。「第一輪略過無有效字音的注音」只適用繁體中文，會在第一輪先略過目前不可能形成有效讀音的符號，第二輪仍可選到。

語音回饋與朗讀後行為

選列、選格、選定後朗讀可分別開關。開太多提示可能干擾理解，開太少則可能無法確認掃描位置；請依聽覺、環境與任務選擇。

朗讀後

繼續輸入（關閉）

朗讀後保持一般溝通板，可立即繼續編輯或加入內容。

重播控制

鎖住剛朗讀的訊息，只掃描「重播」、「下一句」與「編輯」，避免誤改已說出的內容。

對話顯示

同樣提供三個控制，並放大目前訊息；最多顯示兩則先前確實朗讀過的訊息，方便面對面的對話者閱讀。

「下一句」會清空已完成訊息並開始下一句；「編輯」回到原訊息繼續修改；「重播」再次朗讀鎖定的訊息。未朗讀的草稿不會出現在對話內容中。

輸入與顯示

  • 手機／外接按鍵：一般實體或藍牙按鍵。
  • 音量鍵：只接受裝置音量鍵作為開關。
  • 相機動作：使用長眨眼或臉頰抽動；請閱讀相機動作開關專頁。
  • 按鍵＋相機動作：同時保留兩種輸入；應分別測試，避免一次動作產生兩次啟動。
  • 關閉：停用外部開關輸入，供設定或排除問題。

「輸入測試」可檢查每次動作是否只記錄一次，以及感應式輸入在放鬆時是否產生雜訊。正式使用前，應以平常姿勢與速度測試。

持續連選

只適用相機動作。開啟後，一次持續動作可選定目前區塊，再選第一列與第一格；到達格子後就會停止，必須先放鬆才能再次啟動。這能減少選第一格所需的重複動作，但不適合難以穩定放鬆或容易維持過久的使用者。開啟後請重新執行輸入測試及完整溝通流程。

待機時間

預設關閉。設定 1、5、15 或 30 分鐘後，只有掃描已停止時才開始倒數；正常掃描、輸入與朗讀期間不計時。進入待機後，App 會降低自身畫面亮度及相機分析負載，但不關閉螢幕、相機或 App。下一次相機動作只會恢復掃描，不會同時選取內容。

顯示對比

內建預設包含一般、高對比亮色與高對比暗色。請在使用者實際觀看距離與環境光線下選擇；高對比不一定適合所有人，也不應只依螢幕截圖判斷。

版面與詞彙

「每列最多格數」會同時影響目標大小與掃描等待；增加格數不是單純變快，因為格子會變小。英文候選字典與版面內容可由協助者編輯，一行一個項目。修改前請保留原始內容，並在主畫面確認所有常用操作仍可到達。

恢復預設會取代個人化設定。

0.4.0 會先顯示確認。仍請先確認使用者知道將失去哪些自訂內容，再執行恢復預設；此操作不是一般的問題排除第一步。
