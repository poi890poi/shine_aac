我想說 0.4.0

相機動作開關

由協助者設定長眨眼或臉頰抽動，讓一次可靠動作等同一次開關啟動。

先求穩定，再求速度。

請先選擇使用者最容易重複、最少誤觸的動作。校正後要在實際坐姿、裝置位置與光線下測試；移動手機後也要重新測試。

使用前準備

  • 由視力與手部操作能力足以完成設定的協助者操作此頁。
  • 固定手機或平板，讓使用者能維持舒適、自然的姿勢，不要為了鏡頭刻意抬頭或靠近。
  • 臉部保持在預覽中央，雙眼、鼻子與兩側臉頰要清楚可見；避免強烈背光、臉部陰影或鏡頭髒污。
  • 相機影像只在裝置上分析；我想說不會儲存或上傳相機畫面。Google ML Kit 可能依其文件傳送診斷與使用量指標，但不包含相機畫面或 AAC 訊息。
0.4.0 可選用 USB UVC 相機

具備 USB Host／OTG 的 Android 裝置可直接選擇相容的 UVC 網路攝影機。外接相機的供電、格式及相容性因硬體而異；第一次連接前請先閱讀USB UVC 相機專頁，並在實際組合上重新校正與測試。

完整設定步驟

  1. 在主畫面選擇「設定」。
  2. 把「開關輸入」設為「相機動作」，或需要保留實體按鍵時選擇「按鍵＋相機動作」。
  3. 選擇「相機設定」，並允許相機權限。
  4. 在「動作」選擇「長眨眼」或「臉頰抽動」。
  5. 確認預覽中的臉部完整、清楚、置中。需要時用正常的相機「縮小／放大」調整取景。
  6. 選擇「開始設定」，依畫面及語音提示完成個人化校正。
  7. 校正結束後，在同一頁連續嘗試目標動作與自然休息。畫面應只在有意動作時顯示「已接受」。
  8. 選擇「完成」回到設定頁，再選擇「儲存」。回到溝通板後，以實際掃描完成數次選列與選格。
不要只看校正成功。

至少要驗證三件事：有意動作能啟動、自然眨眼或表情不會啟動、連續使用後仍能維持。任何一項不穩定，都應先調整姿勢、光線、動作或維持時間。

選擇適合的動作

長眨眼

適合能刻意閉眼一段時間，而且自然眨眼明顯較短的使用者。校正會先記錄放鬆狀態，再收集慢眨眼。請依提示完成多次清楚的慢眨眼，不要一直閉眼。

臉頰抽動

適合能重複做出局部臉頰動作的使用者。校正先學習放鬆臉部，再收集六次臉頰抽動；每次之間要回到自然放鬆。預設偵測可使用，但個人化校正通常更可靠。

維持時間

維持時間是動作必須持續多久才算一次啟動。太短容易誤觸，太長則費力且反應慢。每次只調整一小步，接著同時測試有意動作與自然休息。不要用掃描速度掩蓋動作偵測不穩定。

相機縮放與位置

縮放只改變相機取景，不會放大 App 的一般介面。臉部應占預覽的主要部分，但仍保留完整眼睛與臉頰；若臉部被裁掉，請先縮小。裝置位置或使用距離改變後，先回到相機設定確認取景與測試結果。

持續連選（選用）

一般相機動作每次啟動後都要先放鬆。「持續連選」讓一次較長的動作依序選目前區塊、第一列及第一格，最多到一個格子就停止；不會因持續閉眼或維持臉頰動作而無限重複。只有確認使用者能清楚開始及放鬆動作後才開啟，並以完整句子測試誤選與疲勞。

待機仍可用相機恢復

若協助者設定「待機時間」，倒數只在掃描停止後進行。待機會降低畫面亮度與相機分析頻率，但不關閉相機；下一次有效動作只會恢復掃描，不會選取當時的項目。若恢復不可靠，請關閉待機並重新檢查校正與環境光線。

問題排除

一直顯示找不到臉或分析暫停
  • 擦拭鏡頭，改善正面光線，減少背光。
  • 把完整臉部移到預覽中央；必要時縮小相機。
  • 確認沒有口罩、手或物品遮住眼睛與臉頰。
自然眨眼或表情也會啟動
  • 稍微增加維持時間，再測試自然休息至少一分鐘。
  • 重新校正，放鬆階段保持自然，不要刻意僵住。
  • 若長眨眼與自然眨眼差異太小，改試臉頰抽動或實體開關。
有意動作常常沒有反應
  • 先確認畫面持續偵測到臉部，再稍微減少維持時間。
  • 重新校正，讓每次示範動作清楚、可重複且彼此相近。
  • 測試疲勞後的動作；若可靠度下降，選擇更省力的動作或實體開關。
換位置後變得不準

回到相機設定，重新置中、調整相機縮放並測試。個人校正可以保留，但若光線、角度或使用者動作明顯改變，應重新校正。

安全提醒

相機動作輸入不能作為唯一或緊急溝通方式。實際使用前，請準備使用者與協助者都能操作的備用溝通方式。
