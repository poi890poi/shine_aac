# Sustained face-analysis experiment, 2026-09-11

Type: test/tooling and performance research. Only instrumentation and host reporting change; production app, calibrated inputs, settings, camera permissions and CPU default remain unchanged.

Compare serial CPU, serial GPU and single-GPU preparation overlap independently at 320x240, 66 ms source cadence, one face, existing 0.55 tracking/detection thresholds, blendshapes enabled and the unchanged 1000 ms blink classifier. Use the immutable previously declared public timed fixture pack. Repeat complete 15.378-second cycles to cover at least 30 continuous minutes, keeping the native model and classifier alive across cycles. One-minute pilots must pass every positive and negative case before sustained admission. Model construction and 30 warmup samples are outside the timed inference interval.

Each device gets all three conditions. Phone order CPU/GPU/prepared; tablet GPU/CPU/prepared. This first screen has one sustained observation per condition; order and session variance remain limitations, and it cannot choose a production default. A later counterbalanced within-device repeat is needed for a repeatability claim. Stop a clearly failing condition; preserve failures rather than changing classification thresholds. Severe thermal status stops the run with incomplete evidence.

Fixtures supply images, scheduled capture times and case labels. Runtime sees images and timestamps only; labels are post-run evaluation. Every complete positive case must produce exactly one activation; negative cases zero. Count cases individually, retain event identities and missing-frame handling. No private captures or local stimuli. Repeated known fixtures measure stability rather than generalization; there is no fresh holdout in this screen.

SettingsActivity is displayed unchanged with a temporary KEEP_SCREEN_ON window flag. Camera, preview, scanning, speech and mini-game rendering are absent. This is a sustained native pipeline benchmark, not application/optical-rig certification. No calibration is changed. The installed app hash must equal the recorded CPU-default APK. Only the test APK is installed.

Both devices are USB powered at 100% at discovery. Record connected/charging state, display state, brightness mode/value, named thermal-service sensors and in-process status/headroom, PSS and battery counters. Poll headroom every 10 seconds, host diagnostics every 30 seconds. Unsupported counters/headroom are unknown. Battery current at full charge cannot establish device power consumption; no Wh, battery-life or energy-saving claim. Ambient temperature, case insulation and external wattage are unmeasured. Normal OS governors/protection remain enabled. Battery temperature is not SoC/skin temperature.

Between conditions, stop instrumentation, verify display OFF (or existing asleep AOD), cool at least 3 minutes and require battery temperature within 1 C of the initial baseline before starting, with a 15-minute cap; stop if comparability is not restored. This is only a battery-temperature matching proxy, not proof of matched SoC temperature. Never cool or pause within an admitted 30-minute run.

Retain exact per-frame timing, delivery order, drop accounting, blink probabilities, presence and event identities. Long-run landmarks are omitted and represented only by presence; no landmark agreement claim. The harness retains compact sample metadata until final output; PSS growth includes that deliberate retention and is not interpreted as a production leak. Thermal data flushes incrementally to survive an interrupted run. Report early/late five-minute windows using equal complete stimulus-cycle counts, rolling minute timing, p50/p95/p99/max, freshness, gaps, per-case misses/extras and thermal trends. CPU milliseconds are workload, not joules.

Predeclared screening decisions: any incorrect case rejects semantic equivalence for that condition; incomplete data or an accounting/backend/display/charging mismatch prevents a sustained-comparison PASS. A late/early p95 ratio above 1.10 flags degradation for investigation; it is a diagnostic threshold, not statistically established regression or thermal attribution. Improvement beyond noise and energy acceptance cannot be established with this first single-run screen. Default remains CPU regardless of speed ranking.

Cleanup is inside the acknowledged shared device lease, including failures: verify preferences and camera permission unchanged, force-stop the test app, turn off the used displays and verify sleep. Explicitly release device ownership after completion. No production device-test or optical-rig PASS is claimed by this benchmark.
