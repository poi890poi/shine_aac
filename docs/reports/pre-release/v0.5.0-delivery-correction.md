# v0.5.0 delivery correction

Type: release packaging defect; application behavior and artwork are unchanged.

Cause: the release flow copied the detailed version changelog to both artifact
paths while `docs/PLAY_RELEASE_NOTES.md` still described v0.4.1/code61. The
documented Play format was not an executable packaging gate. This allowed the
same user-facing mistake to recur despite the previous written instructions.

Fix: a current-version JSON source generates the pure language-tagged Play
payload. Both packagers validate version, existing listing locales (`zh-TW`,
`en-IN`), 500-character limits and exact generated-document equality before
packaging. Both export `PLAY_RELEASE_NOTES.txt`; the APK ZIP includes it.
The former document fails the new check; six regression cases cover exact
output, stale name/code, Unicode length, locales, invalid text and current data.
The corrected translations contain 132 and 381 Unicode characters respectively.
Both actual packaging commands passed with `-SkipBuild`, exporting identical
Play payloads while preserving the tested APK and signed AAB hashes. This was
packaging verification, not a new application build or physical-device test.

## Download size findings

The tested ARM64 APK is 53,498,593 bytes. Its stored ZIP entries contain:

| Content | Decimal MB |
| --- | ---: |
| Web/game assets and code | 26.08 |
| Native libraries | 12.15 |
| Android bytecode | 8.14 |
| Face model | 3.35 |
| Other resources | 2.02 |

Within game assets, candidate sheets account for 19.91 MB and a cloud review
PNG for 1.25 MB. The builder copies whole scenery/native directories and three
candidate folders. Some old sprite paths remain supported and the flower
source is still loaded, so deleting every candidate image is not yet justified.
This is an identified packaging optimization opportunity, not an app-size fix
already verified. Runtime dependency pruning needs its own asset-load checks.

The previous 172.17 MB download ZIP contains four complete ABI-specific APKs.
It is a distribution bundle, not one device's installed size. A separate ARM64
ZIP now supplies the same tested APK and the corrected Play notes for the
connected phone/tablet. No new physical test is claimed for a notes-only change.
The smaller ZIP is 42,699,910 bytes (SHA-256
`79d44d53046599a6320f400bbeb4f6c598c4ddef109fd0d7e3745c043d39bd99`).
The corrected Play payload and smaller ZIP were downloaded through the existing
user-requested Cloudflare tunnel and verified byte-for-byte against local files.
