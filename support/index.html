支援與回饋

我想說 SayToMe AAC 目前是早期測試中的輔助溝通工具。回饋請盡量提供裝置型號、Android 版本、使用情境與重現步驟。

請不要在公開回饋中提供敏感個人資料、健康資料、照片、影片或可識別使用者身分的內容，除非測試目的確實需要且已取得相關人員同意。

回報問題

  • GitHub 專案：github.com/poi890poi/shine_aac
  • GitHub Issues：github.com/poi890poi/shine_aac/issues

安全提醒

測試期間請保留其他可靠溝通方式，尤其是疼痛、同意、拒絕、不舒服、健康急迫需求或緊急情況。本 app 不是醫療建議，不是完成的臨床產品，也不能取代專業 AAC 評估、語言治療、醫療照護或緊急溝通計畫。

English

SayToMe AAC is an early-development AAC communication tool. For feedback, include device model, Android version, use case, and reproduction steps. Do not post sensitive personal or health information publicly.
