# Sixteen-bird POC and future host selection

Type: new species catalogue and intentional integration behavior. The POC exposes
all 16 species from species-proportions.json through picture-only paged choices.
The reusable host defaults to random selection once at each new round; explicit
manual mode supports POC review. Do not switch birds on a flyby, pause, collision,
drop, or landing. Each species has equal probability; consecutive repeats are valid.
An injectable random source permits deterministic tests without changing gameplay.

Keep magpie and yellow-tit artwork unchanged. Derive remaining species pose sheets
individually from their previous reference designs and construction guides, using
the existing style references. Record prompt/source hashes and per-species crops,
pivots, scale, plumage palette, frame cadence and ground contact. Generated art is
a candidate for review; numerical checks are not aesthetic approval. No generic
shape substitutes or recolored magpies. Preserve readable torso/head size, with
long tails accommodated in the source canvas rather than shrinking whole birds.

Owning boundaries: bird-species, sprite loading/rendering, embed selection policy,
POC picker and artwork catalogue. No changes to flowers/stems/leaves, cloud or
mountain scenery, drop/collision/landing physics, AAC column count or persistent
settings. This prepares the host API; it does not modify the Android app or claim
native integration/release completion.

Risks: pose drift, clipping long tails/wings, unreadable small species, 16-choice
overflow and image memory. Review every native pose and scene, keep fixed uniform
scale per species, use small prepared frame canvases for new art, and page choices.
Tests cover all IDs/assets, original sprite pixels, selection lifecycle/random
boundaries, no mid-round changes, picture-only controls, AAC 3–8, frame bounds and
grass contact. Capture actual phone evidence and always verify displays off.

## Reusable integration contract

`mountBirdGame(container, {speciesSelection: 'random'})` hides the picker and draws
uniformly from the complete roster on `start()` / replay. Omitting both species
options has the same behavior. `getBirdSpecies()` and every emitted event's
`speciesId` expose the current identity. `getSpeciesSelection()` exposes the mode.
`setBirdSpecies(id)` is allowed only in manual mode, between rounds. An explicit
`species` without a mode is a manual override for existing POC callers.

The standalone demo explicitly uses `speciesSelection: 'manual'`. Its URL supports
`?species=mikado_pheasant`; `?selection=random` exercises the future host behavior.
The Android integration still needs to call this API when that work is undertaken.
